# OneScan 1.3 Account Foundation — Real-device QA

บันทึกทุกข้อ: PASS / FAIL / P0 / P1 / P2 + รุ่นเครื่อง + Android + ภาพหน้าจอเมื่อ FAIL
**P0** = Crash, เอกสารหาย/เปิดไม่ได้, Scanner ใช้ไม่ได้เพราะบัญชี/เน็ต, Login wall, รหัสผ่าน/token รั่วบนหน้าจอ, บัญชีคนอื่นเข้าถึงได้, ลบบัญชีแล้วเอกสารในเครื่องหาย

เตรียม: อีเมลจริง 2 อัน (A, B), มือถือ 2 เครื่อง (เครื่อง 1, เครื่อง 2), เครื่อง 1 มี OneScan 1.2.0 พร้อมเอกสาร ≥ 5 ฉบับ (มี 20 หน้า 1 ฉบับ, มีโฟลเดอร์)

## 1. Upgrade จาก 1.2.0 (เครื่อง 1)
| # | ขั้นตอน | ผลที่ต้องได้ |
| --- | --- | --- |
| 1.1 | ติดตั้ง 1.3 QA ทับ 1.2.0 → เปิดแอป | ไม่ถามให้ login, ไม่มี popup บัญชี, ไปหน้าแรกเหมือนเดิม |
| 1.2 | เปิดเอกสารทุกฉบับ, ค้นหาคำในเอกสาร, แชร์ PDF 20 หน้า | ครบ เปิดได้ ค้นเจอ ไม่มีฉบับซ้ำ |
| 1.3 | Force stop ระหว่างเปิดแอปครั้งแรกหลังอัปเดต → เปิดใหม่ | เอกสารครบ |

## 2. ใช้งานโดยไม่สมัคร
| 2.1 | สแกน 3 หน้า → บันทึก → OCR → ค้นหา → PDF → แชร์ | ทำได้ทั้งหมดโดยไม่ต้องมีบัญชี |
| 2.2 | ปิด Wi-Fi + Mobile data → เปิดแอป → สแกน/เปิดเอกสาร/ค้นหา | ใช้ได้ปกติ |
| 2.3 | แท็บ ฉัน | การ์ด "OneScan Account" + ปุ่ม เข้าสู่ระบบ / สร้างบัญชี; การตั้งค่าเดิมอยู่ด้านล่าง |

## 3. สมัคร + ยืนยันอีเมล (อีเมล A)
| 3.1 | สร้างบัญชี: อีเมลผิดรูปแบบ / รหัสสั้น / ไม่มีตัวเลข / ยืนยันไม่ตรง / ไม่ติ๊กยอมรับ | ข้อความภาษาไทยใต้ช่อง ไม่ส่งข้อมูล |
| 3.2 | แตะ "ข้อกำหนดการใช้งาน" และ "นโยบายความเป็นส่วนตัว" | เปิดหน้าได้ |
| 3.3 | สมัครถูกต้อง | ไปหน้า "ยืนยันอีเมลของคุณ" แสดงอีเมล A; ยังไม่ได้เข้าสู่ระบบ |
| 3.4 | "ส่งอีเมลอีกครั้ง" | กดได้หลังนับถอยหลัง 60 วิ; กดถี่ → ข้อความให้รอ |
| 3.5 | "เปิดแอปอีเมล" | เปิดแอปอีเมล |
| 3.6 | แตะลิงก์ในอีเมลบนเครื่อง 1 | เปิด OneScan → "ยืนยันอีเมลสำเร็จ" → ไปที่บัญชี: แสดงอีเมล + "ยืนยันอีเมลแล้ว" |
| 3.7 | แตะลิงก์เดิมอีกครั้ง | "ลิงก์ไม่ถูกต้องหรือหมดอายุ" ไม่ crash |
| 3.8 | สมัครด้วยอีเมล A ซ้ำ | "อีเมลนี้มีบัญชี OneScan อยู่แล้ว" |

## 4. Login / Logout
| 4.1 | ออกจากระบบ → ยืนยัน | "ออกจากระบบแล้ว เอกสารในเครื่องยังอยู่ครบ"; เอกสาร/โฟลเดอร์/ค้นหา ครบ |
| 4.2 | เข้าสู่ระบบรหัสผิด | "อีเมลหรือรหัสผ่านไม่ถูกต้อง" (ไม่มีข้อความภาษาอังกฤษของระบบ) |
| 4.3 | สมัครอีเมล B แต่ยังไม่ยืนยัน → เข้าสู่ระบบด้วย B | "ยังไม่ได้ยืนยันอีเมล" + ไปหน้ายืนยันได้ |
| 4.4 | เข้าสู่ระบบอีเมล A ถูกต้อง | กลับหน้า ฉัน แสดงบัญชี; เมนู บัญชีของฉัน / อุปกรณ์และเซสชัน / ความเป็นส่วนตัว / ข้อกำหนด / ออกจากระบบ / ลบบัญชี; **ไม่มีเมนู Backup/Sync** |
| 4.5 | ปิดเน็ต → กดเข้าสู่ระบบ | "ไม่มีการเชื่อมต่ออินเทอร์เน็ต…" |
| 4.6 | Login แล้ว: Force stop → เปิดใหม่, Restart เครื่อง → เปิดใหม่ | ยังเข้าสู่ระบบอยู่; เอกสารครบ |
| 4.7 | Login แล้วปิดเน็ต → เปิดแอป → สแกน/เปิดเอกสาร → แท็บ ฉัน | Scanner ใช้ได้; ฉัน แสดงบัญชี + "ออฟไลน์" |

## 5. ลืมรหัสผ่าน / รีเซ็ต
| 5.1 | ลืมรหัสผ่าน → อีเมล A | ข้อความ "หากอีเมลนี้เชื่อมกับบัญชี…" |
| 5.2 | ลืมรหัสผ่าน → อีเมลที่ไม่มีบัญชี | ข้อความเดียวกันทุกตัวอักษร |
| 5.3 | แตะลิงก์รีเซ็ต → ตั้งรหัสใหม่ (ทดสอบไม่ตรง/สั้น ก่อน) | "เปลี่ยนรหัสผ่านแล้ว…" → หน้าเข้าสู่ระบบ |
| 5.4 | เข้าสู่ระบบด้วยรหัสใหม่; รหัสเก่าใช้ไม่ได้ | ถูกต้อง |
| 5.5 | **เปิดเอกสารเดิมทั้งหมด + ค้นหา** | เปิดได้ทุกฉบับ (รหัสผ่านไม่เกี่ยวกับการเข้ารหัสเอกสาร) |

## 6. อุปกรณ์และเซสชัน (2 เครื่อง)
| 6.1 | Login อีเมล A บนเครื่อง 2 → เครื่อง 1: อุปกรณ์และเซสชัน | เห็น 2 เครื่อง (รุ่นเครื่อง, ใช้งานล่าสุด), เครื่องนี้มีป้าย "เครื่องนี้" |
| 6.2 | เครื่อง 1: ออกจากระบบอุปกรณ์เครื่อง 2 → เครื่อง 2 เปิดแท็บ ฉัน | เครื่อง 2 แสดง "เซสชันหมดอายุ" ทันที; เอกสารเครื่อง 2 ครบ |
| 6.3 | Login เครื่อง 2 อีกครั้ง → เครื่อง 1: ออกจากระบบทุกอุปกรณ์ | ทั้งสองเครื่องออกจากระบบ; เอกสารครบทั้งสองเครื่อง |
| 6.4 | รีเซ็ตรหัสผ่าน (ข้อ 5) ตอนเครื่อง 2 login อยู่ | เครื่อง 2 ออกจากระบบ |

## 7. ลบบัญชี (ใช้อีเมล B หลังยืนยันแล้ว)
| 7.1 | ลบบัญชี | เห็น 2 ข้อชัดเจน: ข้อมูลบนเซิร์ฟเวอร์ลบหลัง 14 วัน / **ไม่ลบเอกสารในเครื่อง** |
| 7.2 | รหัสผิด / ไม่ติ๊ก "ฉันเข้าใจ" | ปุ่มกดไม่ได้ / "อีเมลหรือรหัสผ่านไม่ถูกต้อง" |
| 7.3 | ลบสำเร็จ | "ได้รับคำขอลบบัญชีแล้ว" + วันที่ (14 วัน); ออกจากระบบ; เอกสารครบ |
| 7.4 | Login อีเมล B อีกครั้ง | แสดง "บัญชีนี้มีกำหนดลบวันที่ …" + ปุ่มยกเลิก → ยกเลิกได้ |

## 8. ภาษา/ธีม/จอ
| 8.1 | ทุกหน้าบัญชีใน ไทย และ English, Light/Dark, ตัวอักษรใหญ่สุด, จอ 360dp | ไม่ตัด ไม่ซ้อน ปุ่มกดได้; ไม่มีชื่อ key หรือข้อความ error ดิบ |
| 8.2 | TalkBack: หน้าเข้าสู่ระบบ/สมัคร | อ่านช่องและปุ่มได้ (รวม แสดง/ซ่อนรหัสผ่าน, ช่องยอมรับ) |
